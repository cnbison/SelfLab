## 核心结论

### 1. PoC 范围（与 Bisen 讨论确认）

| 候选 | 选择 | 理由 |
|------|------|------|
| **关键路径端到端（推荐）** | ✅ 选择 | 1 学生 Alice 200 epoch stub + 50 epoch real LLM 链路 + CLI + Markdown 报告，预估 3-4 天 |
| 多学生 + chat UI 原型 | 否 | 工作量大（1.5-2 周），会压缩 schema 收尾与单测时间 |
| 纯 CLI + 深度 schema 探索 | 否 | schema 已确定，无需先验证 schema |

**选择关键路径端到端**：保留 1 周给 schema 收尾 + 单测 + 文档。

### 2. SubjectMasteryState schema（与 Bisen 讨论确认）

| 候选 | 选择 | 理由 |
|------|------|------|
| **学科×主题二维混合（推荐）** | ✅ 选择 | 对齐 K12 真实场景（学校系统就这么组织）；mastery_state.summary() 可生成 "math: 65 (algebra 45, geometry 71)" 粒度；most_recent_struggling() 可定位到主题粒度 |
| 学科一维扁平化 | 否 | lost 主题粒度信息，AI 教练无法精准定位 |
| 三层：领域 → 学科 → 技能点 | 否 | PoC 阶段过度设计 |

**选择学科×主题二维**：与 K12 真实场景对齐；其他应用（AI 教练 / Personal AI）可复用此 schema 模式。

### 3. 项目位置决策

## 关键技术决策（实施中调整）

### 1. sge/ 包增强（向后兼容）

修改 `sge/sge/context_injection.py` 的 `build_actor_prompt_context`：扩展 duck typing 调用 `mastery_state.most_recent_struggling()` 和 `learning_velocity()`（原版只调 `summary()`）。其他应用受益。

### 2. fixture 设计原则（实施中调整）

- 初版：trajectory 插值 + 随机扰动 → 漂移覆盖趋势（math/algebra 78 → 35 → 100 触顶触底）
- 终版：mastery_drop 强制负 delta + mastery_rise 强制正 delta + 边界 [35, 90] 限制
- 5 阶段：math 失败 1-80 → english 上升 81-120 → emotional 主导 121-160 → breakthrough 161-180 → 巩固 181-200

### 3. R5 数据误用缓解（设计阶段已规划，实施时细化）

- adapter 层 `SAFETY_DIRECTIVE` 强制约束：禁用评判性语言（"你太差了"/"你不行"等）/ 必用建设性语言 / 给具体可执行建议 / 避免高风险建议
- 反向引用：SAFETY_DIRECTIVE 不直接列出禁用词（避免 prompt 子字符串假阳性）
- 单元测试抽样 10 个真实场景验证

### 4. R10 多用户隔离（Phase 3.1 已就绪）

- PoC 阶段单学生，但写测试断言"切换 student_id 时 state 隔离"（`TestR10MultiUserIsolation` 2 tests）

## 关键 Bug 发现 + 修复（实施中累积 7 个）

1. **TwinContextBuilder.build_actor_prompt_context 缺 duck typing** — 新增 most_recent_struggling/learning_velocity 调用
2. **R5 安全约束子字符串假阳性** — SAFETY_DIRECTIVE 改为反向引用
3. **fixture 轨迹设计错误** — 强制 delta 方向 + 边界限制
4. **update_topic delta 计算 Bug** — TopicMastery.update 返回真实 delta，首次创建返回 0.0
5. **e2e 测试 subprocess PYTHONPATH 路径错** — 4 层 `.parent` 修正
6. **报告事件类型分布错** — 从 student_events 列表统计而非 SGE 内部 event
7. **H_self chunk 聚合错** — 按 epoch 范围分组而非数据点切片
